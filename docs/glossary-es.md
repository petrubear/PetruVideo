# Spanish glossary (neutral Latin American Spanish)

One term per concept, used the same way on every screen. Style: no regional slang, no "tu" or "vos" forms; use the
infinitive or the impersonal for actions ("Exportar", "Agregar clip") and plain statements for messages ("No hay
sonido en este clip"). Keep product and technical names as they are (PetruVideo, 1080p, fps, MP4, dB).
