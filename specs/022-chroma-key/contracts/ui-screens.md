# UI: Chroma Key

Overlay panel: a two-segment control "Opacity" and "Chroma key". Chroma key tab: switch "Chroma key", chips "Green" and "Blue" (selected state), button "Pick colour" (then "Tap the colour in the preview" hint, cancel on second tap), sliders "Strength", "Smoothness", "Spill" (0 to 100), switch "Checkerboard (preview only)". All targets at least 48 dp, all controls with content descriptions.
