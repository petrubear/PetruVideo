# Quickstart: Theme Setting

1. `./gradlew --offline detekt lintDebug testDebugUnitTest verifyPaparazziDebug`
2. Unit: `isDark` truth table; repository default, round trip and unknown value (instrumented).
3. On a phone: Settings, Theme, pick Dark with the phone in light mode and back; close and reopen the app; check the look and the selected option; switch the phone mode with Light or Dark chosen and see no change.
