# Quickstart: Voice Split

1. `gradle test` for the DSP, command, and view model tests.
2. `ANDROID_SERIAL=emulator-5554 gradle connectedDebugAndroidTest` for the model run on a synthetic mixture (stems sum to the mixture) and accessibility.
3. By hand on the phone: record yourself singing and playing, select the clip, Split voice, then add reverb to Backing only.
