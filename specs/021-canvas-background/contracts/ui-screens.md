# UI Contract: Canvas Background

- **Entry**: the Effects tab bar with no clip selected shows Background.
- **Panel**: Black chip; a row of 12 colour swatches and Custom (opens the colour picker); a row Blur Light / Medium / Strong; the active choice is marked; each tap applies at once.
- **Accessibility**: swatches are 48 dp with colour names ("Red", "Sky blue"); chips labelled; works in portrait, unfolded and tabletop.
