# UI Contract: Auto Captions

- **Entry**: the Text tab's bar has Add text and Auto captions.
- **Panel**: availability line; language chips (installed languages); Replace switch (on by default); Start. Unavailable states show the reason and, when a language is missing, Open speech settings.
- **Running**: progress bar with a percentage and Cancel, in a live region ("Making captions, 40 percent"); nothing else changes in the project until it ends.
- **Done**: one undo step; a note with the number of captions and skipped phrases.
- **Accessibility**: all controls 48 dp, labelled; works in portrait, unfolded (inspector section), and tabletop.
